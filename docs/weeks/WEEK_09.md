# WEEK 09 — TESTING & BUG FIXING

## Objective
Kiểm tra toàn bộ MVP theo các flow chính và sửa lỗi.

## Prerequisites
- MVP implementation gần hoàn chỉnh.

## Tooling
- Vitest: test runner.
- React Testing Library: frontend.
- Supertest: backend/API.
- Postman hoặc REST Client: manual API checks.

## Test Areas
- [ ] Frontend.
- [ ] Backend.
- [ ] REST API.
- [ ] Task CRUD.
- [ ] Search/filter.
- [ ] Calendar sync.
- [ ] Authentication.
- [ ] Authorization/cross-user access.
- [ ] Chatbot structured actions.
- [ ] Missing/ambiguous clarification.
- [ ] Delete confirmation.
- [ ] Conflict detection.

## Regression Rule
Mỗi bug quan trọng được sửa nên có cách tái kiểm tra rõ ràng.

## Definition of Done
- Core demo flows không có blocker.
- Known issues còn lại được ghi trong `PROGRESS.md`.
- Không thêm feature lớn mới trong tuần testing.
